# codevex-assets

Standalone asset store for CodeVex King of the Hill — banners, loading and
connecting screens and animated GIFs, hot-linkable straight from GitHub raw.

## Contents

| File | Use |
|------|-----|
| `codevex_banner_full_animated.gif` | Full animated server banner |
| `king_of_the_hill_1865x108_animated.gif` | King of the Hill banner (1865x108) |
| `codevex-banner.png` / `codevex-cconnecting.png` | Static banner / connecting image |
| `connecting.png` | Connecting screen image |

## Usage

Link files directly (regular GitHub usage applies):

```
https://raw.githubusercontent.com/Brave-developments/codevex-assets/main/<file>
```

or via jsDelivr if you need a CDN:

```
https://cdn.jsdelivr.net/gh/Brave-developments/codevex-assets@main/<file>
```

Useful as `sv_projectDescription` art, Discord embeds, loading screens and
server-listing images.
